# Finder 新建文件——快速使用说明

访达默认只能新建文件夹，没有内置的“新建空文件”命令。Finder Create File 会把这个功能加入文件夹空白处的右键菜单。

## 安装

1. 解压下载包。
2. 按住 Control 点击 **安装 FinderCreateFile.command**，选择“打开”。本包使用临时签名且未经 Apple 公证，macOS 首次运行时可能要求这样明确打开，或要求到“系统设置 → 隐私与安全性”中允许。
3. 打开“系统设置 → 通用 → 登录项与扩展 → Finder”，如尚未开启，请启用“Finder 新建文件菜单”。
4. 在访达文件夹空白处右键，选择“新建文件”。

本工具不会添加登录项，只在访达调用时运行。需要 macOS 13 或更高版本；安装包同时包含 Apple 芯片（`arm64`）和 Intel（`x86_64`）代码。安装和创建文件不需要 Command Line Tools 或 Microsoft Office；打开、编辑 Word、Excel、PowerPoint 文件时才需要兼容应用。

## 卸载

按住 Control 点击 **卸载 FinderCreateFile.command**，选择“打开”并确认。普通卸载会把 App 移到废纸篓并保留已选文件类型；只有在终端中加 `--purge` 才会同时把扩展设置容器移到废纸篓。来源不明的旧数据不会被自动删除。

本包使用临时签名，不是 Developer ID 签名，也未经过 Apple 公证；安装脚本不会关闭 Gatekeeper，也不会移除 quarantine 属性。
